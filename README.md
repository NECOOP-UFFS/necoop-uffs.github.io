# Site do NECOOP/UFFS

Este é o código-fonte do site do NECOOP, hospedado gratuitamente no GitHub Pages.

## Como o site funciona
O arquivo `index.html` contém a página inicial inteira (HTML + CSS em um só arquivo). O GitHub Pages publica automaticamente qualquer alteração feita neste repositório — não existe "build" nem passo extra.

## Como atualizar o site
1. Entre no repositório no GitHub.
2. Abra o arquivo que quer mudar (ex.: `index.html`).
3. Clique no ícone de lápis (editar) no canto superior direito do arquivo.
4. Faça a alteração.
5. Role até o final da página e clique em **Commit changes**.
6. Em 1–2 minutos a alteração aparece no site publicado.

## Como adicionar um novo post
Peça ao Claude para redigir o post em HTML pronto para colar — basta abrir uma nova página (ex.: `posts/nome-do-post.html`) usando o botão **Add file → Create new file** no GitHub, colar o conteúdo, e adicionar o link dele na seção de posts do `index.html`.

## Endereço do site
Depois de configurado, o site fica disponível em:
`https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`

(ou em um domínio próprio, se você configurar um mais tarde em Settings → Pages → Custom domain)
