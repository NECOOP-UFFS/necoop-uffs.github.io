# Módulo operacional — Cards e distribuição de novas publicações

Este módulo complementa a skill `NECOOP Site Maintenance V2` e deve ser acionado sempre que uma nova notícia, artigo ou conteúdo for publicado no site. É parte do fluxo de publicação, não uma tarefa opcional a ser lembrada posteriormente.

## Gatilho

Após a publicação e verificação pública de uma nova matéria/conteúdo no site, iniciar o pacote de divulgação. Não aguardar um novo pedido do usuário para preparar os materiais.

## Entregáveis obrigatórios por publicação

1. **Card para Instagram:** formato vertical 4:5 (preferencialmente 1080 × 1350 px), texto curto e legível em tela móvel.
2. **Card para X:** formato horizontal (preferencialmente 1600 × 900 px), com título/gancho e identidade NECOOP.
3. **Card para WhatsApp:** formato quadrado (preferencialmente 1080 × 1080 px), adequado ao compartilhamento em grupos.
4. **Texto de apoio por canal:** legenda para Instagram, texto conciso para X e mensagem encaminhável para WhatsApp, sempre com link direto para a matéria.
5. **Pacote organizado:** arquivos com nomes claros, versões finais e prévia para revisão; registrar os caminhos dos arquivos.

## Procedimento

1. Confirmar que a matéria está publicada e que a URL pública abre corretamente.
2. Extrair da versão publicada título, ideia central, dados/prazos essenciais e chamada para leitura. Não inventar informações nem reproduzir alegações que não constem no conteúdo validado.
3. Definir uma mensagem visual central, adaptando densidade e proporção para cada canal. Manter identidade visual do NECOOP e legibilidade em celular.
4. Usar imagem/arte pertinente sempre que disponível. Não deixar post sem imagem: preparar e anexar um card tanto para X quanto para Instagram. Preparar também a versão WhatsApp.
5. Conferir acentuação, datas, números, URL, contraste, margens de segurança e legibilidade em cada formato.
6. Apresentar ao responsável humano os três cards, os textos de apoio e a prévia para aprovação editorial.
7. Após aprovação, salvar os arquivos no local de materiais de divulgação do projeto e, quando fizer sentido para rastreabilidade pública, versionar cópias finais no repositório. Não inserir materiais temporários ou rascunhos no site publicado.
8. Preparar os rascunhos no Buffer para os canais conectados (Instagram e X), anexando obrigatoriamente a imagem correspondente. Não publicar automaticamente: manter como rascunho até autorização explícita.
9. Entregar a versão WhatsApp pronta para encaminhamento manual, com texto curto e link da matéria.
10. Registrar no histórico da publicação: URL, nomes/caminhos dos cards, textos preparados, estado de aprovação e estado dos rascunhos no Buffer.

## Checklist de conclusão

- [ ] Matéria pública conferida
- [ ] Card Instagram 4:5
- [ ] Card X horizontal
- [ ] Card WhatsApp quadrado
- [ ] Imagem anexada ao rascunho do Instagram
- [ ] Imagem anexada ao rascunho do X
- [ ] Textos de apoio por canal
- [ ] Revisão humana solicitada/concluída
- [ ] Buffer mantido em rascunho até autorização
- [ ] Registro dos materiais e status atualizado

## Regras

- A preparação do pacote é obrigatória a cada nova publicação; a postagem efetiva continua sujeita à aprovação humana.
- Nunca afirmar que um rascunho foi criado, que uma imagem foi anexada ou que uma publicação foi enviada sem confirmação operacional.
- Se a matéria não estiver pública, se faltar imagem adequada ou se houver dúvida factual/editorial, sinalizar a pendência e não improvisar.
- Para conteúdos urgentes, priorizar o card informativo e a URL correta, sem eliminar a revisão de fatos e datas.
